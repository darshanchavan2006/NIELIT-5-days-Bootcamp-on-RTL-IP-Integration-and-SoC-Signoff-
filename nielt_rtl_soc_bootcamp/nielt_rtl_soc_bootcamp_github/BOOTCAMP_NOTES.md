# Bootcamp Topics Covered

Based on the practical work documented during the NIELIT bootcamp:

1. RTL coding in Verilog
2. Dataflow and behavioral modeling
3. Testbench development
4. Verilator compilation and simulation
5. VCD waveform generation
6. GTKWave waveform analysis
7. Yosys RTL synthesis
8. RTL processing and optimization
9. Design statistics
10. Graphviz design visualization
11. Synthesized Verilog/netlist generation
12. Basic RTL-to-synthesis flow relevant to IP integration and SoC signoff

## Example Flow

```text
Verilog RTL
    ↓
Testbench
    ↓
Verilator
    ↓
Simulation output
    ↓
VCD
    ↓
GTKWave
    ↓
Yosys synthesis
    ↓
Optimization / statistics
    ↓
Netlist / Graphviz visualization
```
