# NIELIT RTL / IP Integration & SoC Signoff Bootcamp

This repository contains the RTL design, simulation, waveform verification, and basic synthesis examples practiced during a 5-day NIELIT bootcamp on **RTL/IP Integration and SoC Signoff**.

## Tools Used

- **Verilog HDL** – RTL design and testbenches
- **Verilator** – RTL simulation and compilation
- **GTKWave** – VCD waveform viewing
- **Yosys** – RTL synthesis and design inspection
- **Graphviz** – RTL/netlist visualization generated by Yosys

## 1. 4x1 Multiplexer

Implemented a 4-to-1 multiplexer using two RTL coding styles:

- Dataflow modeling
- Behavioral modeling

For inputs `I0`, `I1`, `I2`, `I3` and select `SEL[1:0]`:

| SEL | Output |
|---|---|
| 00 | I0 |
| 01 | I1 |
| 10 | I2 |
| 11 | I3 |

The testbench checks all four select combinations and generates a VCD waveform for GTKWave.

## 2. 4-bit Up Counter

Implemented a synchronous 4-bit up counter with:

- Clock input
- Active-high reset
- 4-bit count output
- Simulation testbench
- VCD waveform generation

The counter increments on each positive clock edge and rolls over from `1111` to `0000`.

## 3. Yosys RTL Synthesis

A simple 2-input AND gate is synthesized using Yosys.

The synthesis flow demonstrates:

```text
Verilog RTL
   ↓
Yosys read_verilog
   ↓
Process / optimization
   ↓
Technology-independent netlist
   ↓
Yosys show
```

The design can be visualized using the Graphviz output generated by Yosys.

## Verilator Simulation

Example:

```bash
verilator --binary -j 0 --Wall up_counter_4bit.v up_counter_4bit_tb.v \
  --top up_counter_tb --timing --CFLAGS "-std=c++20"
```

Then:

```bash
./obj_dir/Vup_counter_tb
```

If the testbench generates a VCD file:

```bash
gtkwave up_counter_4bit.vcd
```

## Yosys

Run:

```bash
yosys -s yosys_commands.ys
```

The synthesis report and design representation are generated by Yosys.

## Learning Outcome

The bootcamp provided hands-on exposure to a basic RTL-to-simulation-to-synthesis flow:

**RTL Design → Testbench → Verilator Simulation → GTKWave Verification → Yosys Synthesis → Netlist/Design Visualization**

> This repository is an educational implementation created during RTL/IP integration and SoC signoff training.
